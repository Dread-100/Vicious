Vicious v0.5 — 累積保存 / シャッフル・固定 / 覚醒展開判定 / 自動更新

主な変更
1. 保存形式を「日ごとのデータセット」から「全試合の累積DB」に変更
   - matchId単位で追加・更新するため、別の日を同期しても過去戦績を消しません。
   - v0.4までの vicious.datasets.v1 は初回起動時に自動移行します。
   - 書き込み前のバックアップもブラウザ内に1世代保存します。

2. シャッフル / 固定
   - VSモバイル側の選択中タブやURLパラメータから自動判定を試みます。
   - 総合画面上部で「全体 / シャッフル / 固定 / 未判定」を切替できます。
   - 判定できなかった日は「修正」から s=シャッフル / f=固定 を手動指定できます。

3. 覚醒評価を修正
   - 4人分の撃墜タイミングを同期します。
   - 相方が自分の1落ち前に2回落ちた試合を「後落ちルート」として分離します。
   - 通常展開の1落ち前覚醒率と、後落ちルートの1落ち後覚醒率を別表示します。
   - 旧同期データは相方撃墜時刻を持たないため、この2指標の母数から外します。

4. 自動更新
   - service workerをnetwork-firstに変更。
   - version.jsonを確認し、新版があればアプリ内に更新ボタンを表示します。
   - GitHubへ新しい版をアップロードした後は、iPhone側でファイルを入れ直す必要はありません。

5. 直接受け渡し改善
   - CompressionStream対応Safariでは同期JSONをgzipしてURLフラグメントでViciousへ直接渡します。
   - 大量試合でもJSONコピペに落ちにくくしています。

重要
- v0.5は同期情報を増やしたため、ブックマークレット側の既取得記録キーをv2にしました。
  初回だけ、その日について過去試合も再取得します。Vicious側ではmatchIdで更新されるため二重登録されません。
- ホーム画面の独立WebアプリとSafariは保存領域が分かれることがあります。
  v0.5のmanifestはdisplay=browserに変更しており、今後はSafari版を本体として使う設計です。

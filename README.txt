Vicious v0.6

変更点
- 各日付を選ぶ戦績画面から、表示されている日付をまとめて同期できます。
- 既取得のmatchIdは詳細を再取得しません。新規分だけ取得します。
- 既存戦績のシャッフル/固定は、日付ページを確認しただけでmodePatchesにより補正できます。詳細の取り直しは不要です。
- 日別詳細ページから実行した場合は、その1日だけ同期します。
- 過去データはVicious側に累積され、別の日を同期しても消しません。

使い方
1. GitHub Pages側のファイルをv0.6へ更新。
2. SafariのVicious同期ブックマークURLをvicious_bookmarklet.txtの1行に置換。
3. VSモバイルの「各日付を選ぶ画面」でVicious同期を実行。
4. 表示中の日付をまとめて確認し、未取得試合だけ取得。
5. Viciousへ送る。

注意
- 初回は未取得試合が多いほど時間がかかります。2回目以降は差分だけです。
- 出撃形式がDOMから判定できない識別値だけ、最初の1回シャッフル/固定を尋ねます。

Vicious v0.2

■ 今回の変更
- Safari同期 v4: 一度同期完了した「同じ日付・同じ店舗」の日別ページは、2回目以降は取得をスキップします。
- Vicious本体: 同じ日付・同じ店舗のJSONを再度読み込んでも二重登録しません。
- v3同様、4WINS等の連勝表示を自分名と誤認する問題を修正済み。
- 最終JSONに詳細ページURL/piは残しません。

■ Safariショートカットの作り方
1. ショートカットアプリで「Vicious同期」を開く。
2. 「WebページでJavaScriptを実行」の中身を vicious_sync_v4.js に全置換。
3. そのアクションを「6回繰り返す」の中に入れる。
4. 繰り返し結果の「最後の項目」を取得。
5. その結果を「クリップボードにコピー」。
6. 最後に通知を出してもOK。

構造:
SafariのWebページを受け取る
↓
6回繰り返す
  └ WebページでJavaScriptを実行
↓
繰り返しの結果 → 最後の項目
↓
クリップボードにコピー

■ 同期の使い方
1. SafariでVSモバイルにログイン。
2. 戦績 → クラスマッチG → 同期したい日付 → 日別の試合一覧を開く。
3. Safari共有ボタン → Vicious同期。
4. 一覧取得中は「一覧 1/6 ...」のように表示。
5. 再度Vicious同期を実行すると続きから進む。
6. 詳細取得中は「詳細 7件完了・残り49件」等。
7. 最後まで終わるとJSONがクリップボードに入る。
8. 同じ日付・店舗でもう一度実行すると「同期済み: ...（取得をスキップ）」になります。

※ iOSのタイムアウト対策で、1タップですべて終わらない場合があります。
※ 途中経過はSafari側に保存されるので、止まっても同じ日付で再実行すれば続きから進みます。
※ 同じ日付でも別店舗なら別データとして扱います。

■ Vicious本体の使い方
1. ViciousフォルダをHTTPSで静的ホスティングします（GitHub Pages / Cloudflare Pages / Netlify等）。
2. iPhoneのSafariでViciousのURLを開きます。
3. 右上の「＋」→「戦績を読み込む」。
4. 「クリップボードから貼る」または入力欄を長押し→貼り付け。
5. 「読み込む」。
6. 総合 / 立ち回り / 覚醒 / 機体相性 / 時間帯 を下タブで確認できます。
7. Safari共有 →「ホーム画面に追加」でアプリ風に使えます。
